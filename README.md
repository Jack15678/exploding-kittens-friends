# 爆炸猫 · 好友厨房

《爆炸猫：灾难食谱》的非官方浏览器实现，供自己和朋友同乐。奶油粉与薄荷绿的可爱界面、原创 SVG 猫咪牌面、中文玩法、18 道食谱。无需账号。

**在线游玩：[爆炸猫 · 好友厨房](https://jack15678.github.io/exploding-kittens-friends/)**

## 本地开始

需要 Node.js 22 或以上。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5174/ 。先点「猫咪陪练」即可本地开局；好友桌由一人「开一间好友厨房」，其他人输入八位房间码或打开邀请链接。

`127.0.0.1` 链接只能在当前电脑打开。让远方朋友访问，需要先把网站部署到共同可访问的 HTTPS 地址。部署后房间码仍由房主浏览器创建。

## 已实现

- 2–5 人好友桌；本地练习；房主可添加猫咪陪练。各食谱有独立人数范围。
- 121 张基础卡池、30 种牌型、18 道食谱（15 个主题及 3 个双人变体）。食谱库可直接查看当前人数的配牌数量。
- 抽牌、拆弹与秘密插回、内爆猫正反面、攻击累加、Nope 连锁、NOW 插入响应、预知/重排/分享未来、二三张组合、标记、截牌、垃圾回收、吠叫猫、流浪猫与猫原子弹。
- 所有存活玩家明确放行后才执行行动；可以在窗口使用响应牌，机器人会自动响应。真人没有自动超时。
- 房主保存完整牌局；其他玩家只收到自己的手牌和可公开信息。牌局记录、历史看牌信息、卡牌图鉴、手机布局。
- 手牌按功能类别自动整理，同名牌相邻，抽到新牌后自动归位；居中呈扇形，鼠标悬停时斜向上浮放大。手机点击抬起选中，再点操作区按钮出牌。牌多时分排，无横向滚动条。键盘可用方向键浏览、空格选中。
- 同一标签页刷新恢复身份、手牌和未完成步骤。玩家掉线时暂停；连接恢复后继续。房主刷新后，朋友自动重连。

陪练只根据自己的玩家视图决定行动，不读取牌堆或其他手牌；策略比较简单，用来熟悉玩法。

## 联机与 GitHub Pages

联机架构参考同级 `wizard-friends`：Vite 静态网页 + PeerJS 信令 + WebRTC 数据通道。**GitHub Pages 托管网页，牌局不通过 GitHub API 同步。** 房主是规则和状态的权威，适合彼此信任的好友。

代码仓库：[Jack15678/exploding-kittens-friends](https://github.com/Jack15678/exploding-kittens-friends)。`.github/workflows/pages.yml` 在推送 `main` 时执行规则测试、构建并部署；GitHub 仓库 Settings → Pages → Source 使用 **GitHub Actions**。Vite 使用相对资源路径，兼容项目子目录。

默认使用 PeerJS 的公共信令服务和默认 ICE 配置。部分校园网、公司网或移动网络可能需要 TURN。可参考 `.env.example` 配置自己的服务后重新构建；前端的 `VITE_*` 值会进入构建产物，不能在其中放长期管理密钥。

没有账号系统、云端存档或房主迁移。关闭房主标签页后，房间暂时不可用；原标签页恢复才可继续。主动「关闭厨房」会结束房间。无痕窗口关闭、清除站点数据或存储被禁用时，无法保证恢复。不要复制房主正在游戏的标签页，避免两个页面争用同一房主身份。

## 验证

```sh
npm test
npm run build
```

规则测试包含全部食谱的完整模拟对局、逐步卡牌守恒检查、攻击/否决/内爆/偷牌爆炸/私密信息、身份绑定、并发响应和保存恢复。构建输出位于 `dist/`。

真实浏览器验证需要安装 Chrome，并先在另一个终端启动 `npm run dev`：

```sh
npm run test:open
npm run test:browser
npm run test:network
npm run test:close
```

脚本通过 Playwright CLI 运行。浏览器检查覆盖手机/桌面布局、食谱、整局陪练、刷新、结算和退出；联机检查创建三个隔离浏览器上下文，使用真实公共 PeerJS/WebRTC，检查加入、双方刷新、手牌过滤、并发放行、完整结算和关闭房间。网络服务不可用时该检查会失败，不会自动换成模拟传输。截图保存在本地忽略目录 `output/playwright/`。

## 代码与规则依据

- `src/cards.js` / `src/recipes.js`：卡牌与食谱数据。
- `src/game.js`：纯规则状态机、命令校验与玩家视图。
- `src/room.js` / `src/room-transport.js` / `src/session.js`：房间、连接、身份与本地恢复。
- `src/bot.js`：仅使用玩家视图的陪练。
- `src/main.js` / `src/art.js` / `src/style.css`：交互、原创插图与响应式界面。
- [规则来源、食谱差异与实现约定](docs/RULES.md)。
